This is a complete AI assisted project.

This is a small tool to get product data from gumroad; this tool is to be used as a part of another project's helper. This script 
downloads the product data, the response from the API endpoint is cached and reused,

The following providers / agents and models are used, through IntelliJ IDEA, the initial project is generated 
through OpenCode:
- OpenCode Deepseek V4.1 Flash     
- OpenCode nemotron-3.5-lightning
- Junie Gemini 3.7 Flash
- llama.cpp Qwen2.5 Code
